# React Router Installation

if you want to version specification than use - npm install react-router-dom@6  
if you want to install latest react version than use - npm install react-router-dom

index.css is generally used for global styles.

App.css is generally used for application-level layout and styling.

Important: Both files contain normal CSS. Neither file automatically limits styles to a particular component.

What is Routing in React?
Routing is the process of navigating from one page to another in an application based on the URL, without reloading the entire website.

eg- home , about , contectus , etc

What is React Router?
React Router is a library that helps you implement routing in React applications.

The main difference is: StrictMode helps you find bugs, while BrowserRouter enables navigation between pages.

Routes renders the best matching route from its children, whereas Route defines the URL path and the corresponding React element.
